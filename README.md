# The Death of the Department Store

Scrollytelling data story: US retail sales by kind of business, 1992–2026 (US Census Monthly Retail Trade via FRED). Built with the [scrollytelling kit](https://github.com/anriueno/scrollytelling-kit) (`/scrollytelling` Claude Code skill) — see `STORYBOARD.md` for verified facts, scenes and caveats (nominal dollars; department-store series discontinued after March 2025).

```bash
npm install && npm run dev     # http://localhost:5173
npm run build                  # dist/
```
